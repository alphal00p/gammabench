# Preserved benchmark results

These reports are generated by the same analysis code used for new benchmark
runs. They retain original measurements and source identities; no new generation
study was performed during this import. Open an HTML report locally, or inspect
its analysis JSON and CSV files directly on GitHub.

| Study | Standard report | Snapshot |
|---|---|---|
| Native generation/count | [HTML](generation-count-20261011/index.html) | [Evidence](../../snapshots/historical/generation-count-20261011/snapshot.json) |
| Owned graphs and symmetry factors | [HTML](generation-materialized-20261012/index.html) | [Evidence](../../snapshots/historical/generation-materialized-20261012/snapshot.json) |
| Native signed/routed diagrams | [HTML](generation-signed-routed-20261013/index.html) | [Evidence](../../snapshots/historical/generation-signed-routed-20261013/snapshot.json) |
| Public full FeynmanDiagram objects | [HTML](generation-full-public-20261014/index.html) | [Evidence](../../snapshots/historical/generation-full-public-20261014/snapshot.json) |

The contracts differ. Counts, materialized incidence, signed/routed records and
full objects are not interchangeable stopwatch endpoints. Each report shows
qualification, censoring, missing metrics, measured scope and source provenance.
Full objects include local numerator fragments and projectors; final aggregate
numerator multiplication is excluded from the generation completion clock.

Rebuild a report into a new destination:

```sh
gammabench report snapshots/historical/generation-full-public-20261014 --output results/full-report --baseline baseline
```

Browse and compare these reports on [GitHub Pages](https://alphal00p.github.io/gammabench/).
Downloaded reports also work offline. JSON and CSV remain readable without a browser. Raw large profiles and
full-graph qualification dumps belong to the linked release evidence archives;
committed snapshot records and controls preserve their original file hashes.

[Download raw evidence and checksums](https://github.com/alphal00p/gammabench/releases/tag/v0.1.0).
The [artifact index](../../artifacts.json) binds each archive to its snapshot.
